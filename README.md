# RSSchool CV

## Deploy: https://quoralis.github.io/rsschool-cv

### Project Description
This is a training assignment for the RSSchool course covering the basics of HTML, CSS, and Git. The project features a semantic CV (resume) layout built with valid HTML5 and CSS3.

### Technologies Used
- HTML5 (Semantic elements)
- CSS3 (Flexbox/Grid, Responsive design)
- Git (Branching, Pull Requests)
